# <span class="wordmark">Lauda</span>へようこそ 👋

<span class="wordmark">Lauda</span>は2つのパネルで構成されたMarkdownエディタです。左側で書くと、右側にフォーマットされた結果が入力と同時に表示されます。

これは名称未設定の書類なので、自由に試してみてください。残したい場合は⌘Sで保存し、不要ならそのまま閉じてください。このガイドは**ヘルプ → ようこそガイド**からいつでも開き直せます。

## 書く

テキストは**ボールド**（⌘B）、*イタリック*（⌘I）、`コード`にできます。テキストを選択して⌘Kを押すと[リンク](https://daringfireball.net/projects/markdown/)になります。選択範囲の上にURLをペーストしても同じです。

コードの外で`->`や`<-`と入力すると、→や←に変わります。

`(`、`[`、`*`、`"`を入力すると、閉じる記号も一緒に入り、カーソルはその間に置かれます。テキストを選択していると、その範囲を囲みます。

> 引用はこのように表示されます。

## リスト

- 項目の最後でReturnキーを押すと、次の項目が始まります
- TabとShift+Tabでインデントを増減できます
  - このように

1. 番号付きリストも続きます
2. 次の番号が自動で入ります

### タスク

- [x] <span class="wordmark">Lauda</span>を開く
- [ ] すばらしい文章を書く

## コード

```swift
struct Greeting {
    let name: String

    func sayHello() -> String {
        "Hello, \(name)!"
    }
}
```

## 画像

画像をエディタにドラッグするか、スクリーンショットをペーストすると、書類と同じ場所にコピーされ、Markdownも自動で入力されます。画像の保存先フォルダが必要なので、先に書類を保存してください。

## 使いこなす

- ツールバーの**目次**ボタンで見出しの一覧を表示し、その場所へ移動できます。
- 2つのパネルは一緒にスクロールします。
- フォント、サイズ、外観、改行の設定は**設定**（⌘,）にあります。
