# Boas-vindas ao <span class="wordmark">Lauda</span> 👋

O <span class="wordmark">Lauda</span> é um editor de Markdown com dois painéis: você escreve à esquerda e vê o resultado formatado à direita, atualizado enquanto digita.

Este é um documento sem nome, então fique à vontade para experimentar. Para guardar, salve com ⌘S; se não quiser, é só fechar. Você pode reabrir este guia quando quiser em **Ajuda → Guia de Boas-Vindas**.

## Escrevendo

O texto pode ficar em **negrito** (⌘B), *itálico* (⌘I) ou virar `código`. Selecione um trecho e use ⌘K para transformá-lo em [link](https://daringfireball.net/projects/markdown/), ou cole uma URL sobre a seleção.

Digite `->` ou `<-` fora de código e eles viram → e ←.

Digite `(`, `[`, `*` ou `"` e o fechamento vem junto, com o cursor no meio. Com um texto selecionado, o par envolve a seleção.

> Citações ficam assim.

## Imagens

Arraste uma imagem para o editor, ou cole uma captura de tela, e ela é copiada para junto do documento, com o Markdown já escrito. Salve o documento antes, para a imagem ter uma pasta para onde ir.

## Para se localizar

- O botão **Sumário** na barra de ferramentas lista os títulos e leva até eles.
- Os dois painéis rolam juntos.
- Fontes, tamanhos, aparência e quebras de linha ficam em **Ajustes** (⌘,).
