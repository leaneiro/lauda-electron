# 欢迎使用 <span class="wordmark">Lauda</span> 👋

<span class="wordmark">Lauda</span> 是一款双栏 Markdown 编辑器：你在左侧书写，右侧会随着输入实时显示排版后的结果。

这是一份未命名的文稿，尽管随意尝试。如果想保留，请按 ⌘S 保存；否则直接关闭即可。你可以随时通过**帮助 → 欢迎指南**重新打开本指南。

## 书写

文本可以设为**粗体**（⌘B）、*斜体*（⌘I）或 `代码`。选中文本后按 ⌘K 可将其变成[链接](https://daringfireball.net/projects/markdown/)，也可以直接在选中的文本上粘贴 URL。

在代码之外输入 `->` 或 `<-`，它们会变成 → 和 ←。

输入 `(`、`[`、`*` 或 `"`，闭合符号会一起出现，光标停在中间。选中文本时，这对符号会把它包起来。

## 图像

将图像拖入编辑器，或粘贴屏幕截图，它会被拷贝到文稿旁边，并自动写好 Markdown。请先保存文稿，这样图像才有文件夹可以存放。

## 快速上手

- 工具栏中的**目录**按钮会列出所有标题，并可跳转到对应位置。
- 两个栏会一起滚动。
- 字体、大小、外观和换行设置都在**设置**（⌘,）中。
