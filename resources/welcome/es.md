# Te damos la bienvenida a <span class="wordmark">Lauda</span> 👋

<span class="wordmark">Lauda</span> es un editor de Markdown con dos paneles: escribes a la izquierda y ves el resultado con formato a la derecha, actualizado mientras escribes.

Este es un documento sin título, así que experimenta con libertad. Si quieres conservarlo, guárdalo con ⌘S; si no, simplemente ciérralo. Puedes volver a abrir esta guía cuando quieras desde **Ayuda → Guía de bienvenida**.

## Escribir

El texto puede ir en **negrita** (⌘B), *cursiva* (⌘I) o como `código`. Selecciona un texto y pulsa ⌘K para convertirlo en un [enlace](https://daringfireball.net/projects/markdown/), o pega una URL sobre la selección.

Escribe `->` o `<-` fuera del código y se convertirán en → y ←.

Escribe `(`, `[`, `*` o `"` y el cierre llega solo, con el cursor en medio. Si hay texto seleccionado, el par lo envuelve.

> Las citas se ven así.

## Imágenes

Arrastra una imagen al editor, o pega una captura de pantalla, y se copiará junto al documento con el Markdown ya escrito. Guarda antes el documento, para que la imagen tenga una carpeta a la que ir.

## Para orientarte

- El botón **Índice** de la barra de herramientas muestra los títulos y te lleva a ellos.
- Los dos paneles se desplazan juntos.
- Los tipos de letra, tamaños, el aspecto y los saltos de línea están en **Ajustes** (⌘,).
